# Ellie's Good Deed Animals

A little phone game for Ellie. Do a good deed, tick it off, and tap the egg to hatch an animal for your collection.

**Play it:** https://lukemerrett.github.io/ellies-good-deed-animals/

- 3 good deeds at a time, picked from 160 across 8 categories: Outside, Round the House, Friends & Family, Art & Making, Explore & Adventure, Nature & Animals, Learning, and Music & Moving.
- Each deed has an egg. Its pattern shows how special the creature inside is: Everyday, Rare, or Magical.
- 54 creatures from around the world, all drawn in code as SVG (no emoji, no image files).
- "Different deeds please" swaps the deeds and keeps the eggs.
- My Animals shows everything found so far. Creatures not found yet show as grey silhouettes.
- Progress is saved in the browser's `localStorage` on that device. There is a backup code under "For grown-ups".

Plain HTML, CSS and JavaScript with no build step. Open `index.html` to run it.
